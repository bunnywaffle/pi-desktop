Capabilities

Engineered For Focus and Stability

Portable Zero-Install

Standalone single executable for Windows. Run anywhere with no installation or administrative permissions required.

Session & Model Persistence

Remembers your exact active session, working directory, chosen model, and reasoning effort across app restarts.

Auto-Healing RPC Bridge

Supervises the background Pi daemon over buffered stdio, auto-recovering connections without dropping your input prompt.

Syntax Highlighting & Copy

GitHub-Flavored Markdown rendering with Prism syntax highlighting and one-click code block copying.

TUI Modal Interception

Transparently routes interactive CLI questions and confirmation prompts into native desktop dialogs.

Custom OpenAI Endpoints

Connect local Ollama, LM Studio, vLLM, or self-hosted API endpoints with custom URLs and headers.

Architecture

Unmodified Upstream Engine

Pi agent remains the sole source of truth. The GUI operates as an external supervisor.

Layer 1
Desktop Frontend

React 18 interface handling chat streams, model search, session management, and settings.

Layer 2 • Bridge
Electron IPC & RPC Supervisor

Buffered stdin/stdout streaming, process watchdog, auto-restart, and TUI dialog translation.

Layer 3
Pi Coding Agent Engine

Official core agent by Earendil Works. Autonomous tools, model routing, and JSONL sessions.

Upstream compatibility guaranteed with future Pi versions. pi.dev →
