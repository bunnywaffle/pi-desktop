Engineered For Reliability

Everything You Need In A Coding Workstation

Pi Desktop is built from the ground up as a native companion that enhances Pi without getting in the way.

Zero-Install Portable Binary

Distributed as a single standalone executable (Pi Desktop-Portable.exe). No installers, no registry modifications, no administrator privileges required.

Full State Persistence

Close and reopen anytime. The app remembers your last active session, active project directory, selected model, and reasoning effort level across reboots.

Auto-Healing RPC Engine

Detects Pi installations across npm, pnpm, yarn, bun, or PATH. If the process is disrupted, the bridge automatically restarts and reconnects without losing your prompt queue.

GFM Markdown & Code Highlighting

Stream responses formatted with GitHub Flavored Markdown, Prism.js syntax coloring, one-click code copying, and distinct tool call visualizations.

TUI Question Interception

Interactive TUI questions and terminal confirmation prompts asked by Pi are transparently routed into smooth graphical dialog modals.

Custom OpenAI-Compatible APIs

Connect local models hosted with Ollama, LM Studio, vLLM, or private corporate endpoints with custom base URLs and headers.

Clean Separation of Concerns

How Pi Desktop Works

Pi agent remains the single source of truth for tools, LLMs, and workspace operations.

1. PRESENTATION LAYER
React 18 + Tailwind UI

Model browser, chat streams, session management, markdown renderer, and prompt dock.

2. CONTROL LAYER
Electron 32 IPC & RPC Bridge

Lifecycle supervisor, JSON-RPC streaming over stdin/stdout, auto-reconnect, TUI dialog interceptor.

3. AGENT ENGINE
Pi Coding Agent CLI

Official agent execution engine by Earendil Works. Autonomous tool calls, multi-model execution, session JSONL files.

Zero monkey-patching: fully compatible with future upstream updates to pi.
